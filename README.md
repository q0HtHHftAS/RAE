## What this repo holds

This repo holds game automation files for Anime Expeditions. A macro is a saved list of placement and upgrade steps. It plays one stage with fixed timing. The repo holds one shared configuration file and 15 macros, one for each supported stage.

## Contents

The repo holds the following items:

- `Config/ALL IN ONE.json` holds the shared configuration for the script.
- `Macro/` holds one macro file for each supported stage.
- `noFilter.png` is the banner image for this README.

## Use

Follow these steps:

1. Copy `Config/ALL IN ONE.json` into the location that your script reads.
2. Copy the macro for your stage from `Macro/` into the location that your script reads.
3. Select the macro that matches your stage.
4. Start the stage.
5. Watch the full first run.
6. If the run fails, stop the macro.
7. Make sure that your team and placement match the recorded run.

## Notes

Each macro fits one stage and one team. A macro replays fixed steps at fixed times. It does not react to random events. If the game updates a map, a unit, or an enemy wave, the macro for that stage can fail. Make sure that your team matches the team that the macro was recorded with.

## Warning

Do not run a macro where automation breaks the rules. The account owner carries the risk. A game update or a detection system can block or ban the account.
